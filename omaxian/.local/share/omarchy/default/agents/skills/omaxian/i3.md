# i3 Configuration

Read this before changing keybindings, monitors, window rules, or any other
i3 (window manager) configuration.

Omaxian uses i3 on X11, not Hyprland. Do not edit `~/.config/hypr/` or call
`hyprctl`.

```
~/.config/i3/
├── config                 # include config.d/*.conf, then the active theme's i3.conf
├── config.d/
│   ├── 01_theme.conf      # font, gaps, borders
│   ├── 02_keybindings.conf
│   ├── 03_mousebindings.conf
│   ├── 04_modes.conf
│   └── 05_rules.conf      # assign / for_window
├── picom.conf
├── dunstrc
├── scripts/               # i3_screenshot, i3_lock, i3_term, …
└── kitty/
```

**Key behaviors:**

- After ANY i3 config change, apply with `i3-msg reload`. If reload fails,
  `i3 -C -c ~/.config/i3/config` to validate.
- Theme `client.*` colors are rendered by `omarchy-theme-set` into
  `~/.local/state/omarchy/current/theme/i3.conf` and included after `config.d/*`.
  Do not put lasting color overrides in `01_theme.conf`; they lose to the theme
  file. Gaps, border width, and font stay in `01_theme.conf`.
- `i3 restart` is **not** a full session reload. Log out and back in after
  `PATH` / `OMARCHY_PATH` changes (`~/.xsessionrc`).
- Super+K (or the `?` bar widget) shows this session's i3 binds.

## Keybindings

Edit `~/.config/i3/config.d/02_keybindings.conf`. `$MOD` is Super (Mod4),
`$ALT` is Alt (Mod1).

```
bindsym $MOD+Shift+e exec --no-startup-id thunar
```

View current bindings: Super+K, or `omarchy-menu-keybindings` if you need a
text dump.

**When re-binding an existing key:**

1. Search `02_keybindings.conf` (and `04_modes.conf`) for that key
2. Remove or comment the old `bindsym` before adding the new one
3. Tell the user what the key was previously bound to

`grp:win_space_toggle` is on by default, so **Super+Space never reaches i3**.
The Omarchy menu is Super+L; the command runner is Alt+F2. Do not add
Super+Space binds expecting them to work.

After editing: `i3-msg reload`.

## Display / monitors

Use the Displays panel (Super+Ctrl+D) or:

```bash
omarchy-monitor-list
omarchy-monitor-set
omarchy-monitor-apply
```

Layouts are saved per output topology (including laptop lid). This is not
Hyprland fractional scaling — resolution, on/off, primary, and position via
xrandr.

List outputs: `xrandr`.

## Window rules

Match on X11 class / instance. Discover them with `xprop` (click the window;
read `WM_CLASS`).

Rules go in `~/.config/i3/config.d/05_rules.conf`:

```
assign [class="Firefox"] 2
for_window [class="Omaxian Settings"] floating enable
```

Do not use Hyprland `windowrulev2` syntax.
