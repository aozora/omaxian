Compared 2026-11-27: upstream tags **v4.5.0** and **v4.6.0-rc1** (SHA

`OMARCHY_UPSTREAM_REF=v4.6.0-rc1` in `setup.sh` / `install.sh`. Deltas:

## Upgrading an existing checkout

The install scripts keep an existing clone, so remove it first:

```bash
rm -rf omarchy-quattro
./scripts/install.sh
./scripts/deploy.sh
# then log out and back in (PATH changed in ~/.xsessionrc)
```

Deploying the new shell against the old `default/` leaves new UI strings
untranslated (raw keys such as `network.timedOutConnecting`).
`deploy.sh` does not delete files, so an installed
`omarchy-agent-account-mode` stays until `install.sh` replaces `bin/`.

## Upstream changes that affect installs

| Change | Port handling |
|---|---|
| Themes no longer carry wallpapers | `install.sh` clones `omarchy-themes-backgrounds` at `v2026.11.25` into `omarchy-backgrounds/` and copies them into the themes |
| Themes no longer carry `icons.theme` (Yaru replaced by icon sets) | The v4.5.0 choices are kept in `scripts/lib/theme-icons` and written by `install.sh` for GTK |
| App icon sets in `icons/` (Papercraft default, Arcade, Original) | `install.sh` copies them and draws the current one; pick under **Style → Icons** |
| New `themed/*.tpl` files and `mix*` / `_rgb` placeholders | Render with the port's `omarchy-theme-set-templates` unchanged |

## Icon sets

- Only the shell (launcher, dock, startup settings) prefers a drawn icon over
  the GTK icon theme. Other apps resolve icons their own way, so with Papirus
  or Yaru they may show that theme's icon instead.
- Qt 6.8 ignores SVG `clipPath`, so lines spill outside the shape in
  `omarchy-browser`, `rawmakase`, `herdr` and `herdr-app`.
- `omarchy-icons-install` and `omarchy-icons-remove` have no menu entry; run
  them from a terminal. **Update → Extra Icons** appears for git-installed
  sets.
- **Style → Icons** → Original brings back each app's own icon.
