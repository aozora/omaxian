## Smoke

Do **not** `omarchy-restart-shell` from an agent session. After
`./scripts/deploy.sh`, **log out / log in**, then:

```
omarchy-shell shell ping
omarchy-shell shell listPlugins
```

Click clock (open calendar), tray icons, Settings enable/disable of a bar
widget that also has a panel kind if available. Locale path:
`omarchy-language list` (generation needs root/`localedef`).
