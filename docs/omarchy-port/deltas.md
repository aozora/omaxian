# omaxian vs omarchy-quattro — intentional divergences

The canonical list of every place `omaxian/.local/share/omarchy/shell/` diverges from
`omarchy-quattro/shell/` (the vendored upstream). See
[omarchy-migration.md](omarchy-migration.md) for the migration this feeds.
The tree was named `marcello/` during the 2026-08 port; older phase logs still
use that path.

**Rule:** after any `omarchy-quattro/` bump, re-apply the upstream tree, then
re-apply every row below. A divergence that is *not* listed here is a bug —
either fold it in or delete it.

**Transform ids** (from omarchy-migration.md §2a):
`T1` layer-shell window → X11 dock/overlay · `T2` `HyprlandFocusGrab` → X11
click-outside · `T3` `Quickshell.Hyprland` → `Quickshell.I3` ·
`drop-hyprctl` remove `hyprctl getoption` live-sync · `adapt-poll` IPC push →
timer poll of an X11 script · `pactl` PipeWire → PulseAudio · `local` a
marcello-authored file with no upstream counterpart.

Legend for **Status**: `keep` = permanent X11 divergence · `transient` = exists
only until the named phase, then converges on upstream.
