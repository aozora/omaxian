## What 4.0.5 is (for this port)

Release headline is Qt 6.12 / October Arch packages, Omarchy kernel with BORE,
OPR priority, browser handoff, and a large set of shell/reliability fixes.

The slice that touches Omaxian:

1. **Qt 6.12 palette qualification** — every bare `Color.*` becomes
   `Commons.Color.*` (plus `import qs.Commons as Commons`), including
   port-local widgets (settings, dock, control panel, BarPalette).
2. **Bar startup / restart race** — `pluginObjectOwners` Map + coalesced
   PluginBarApi sync; Indicators load only one orientation tree.
3. **Calendar DST** — month grid walked in UTC; `viewDate` pinned to local noon.
4. **Agents usage** — expired limit windows report 0% (panel + Claude collector).
5. **Helpers** — `omarchy-cmd-present --`, Wi-Fi QR empty-route guard,
   EasyEffects 8 sink resolution, editor `--` operand boundary.
6. **Third-party plugins** — public manifests keep `__sourceDir`;
   `//@ pragma OmarchyLoadPatch` on `shell.qml`.

Skipped entirely: Hermes/OpenClaw self-update, browser Chromium handoff /
`uwsm`, linux-omarchy / Limine / OPR / pacman, NVIDIA/XPS/T2 hardware paths,
upstream idle IdleMonitor / lock recovery, upstream monitor `hyprctl` toggle,
factory-reset / SSH firewall Arch scripts.

## Smoke (after `./install.sh` && `./deploy.sh`, then **log out / log in**)

Do **not** run `omarchy-restart-shell` from an agent session.

```
omarchy-shell shell ping
omarchy-shell shell listPlugins | jq length
```

Then: bar (Indicators not doubled), calendar month step across DST zones if
relevant, agents meter after a reset window, Wi-Fi QR, audio volume with
EasyEffects if installed, theme switch, third-party plugin scripts if any.
