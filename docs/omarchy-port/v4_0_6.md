## What 4.0.6 is (for this port)

Patch release for hiccups in v4.0.5: OpenClaw migration/update path, lock
before suspend, Limine console migration, non-Latin boot passphrase
(`vconsole` / mkinitcpio), TUXEDO drivers on the Omarchy kernel.

**Shell:** only `plugins/lock/Service.qml` differs (`currentlyLocked()` so a
stale property binding cannot skip the real lock before suspend). Lock is
**not ported** — Omaxian uses `i3lock-omaxian` / `xss-lock`.

**Bin:** OpenClaw install/launch/remove + `omarchy-agent` openclaw package
guard. Launch stack / OpenClaw are **not ported** (agents meter stays
meter-only).

Skipped entirely: Arch migrations, mkinitcpio/plymouth vconsole, OpenClaw
CLI tests, ISO / kernel / Limine paths.
