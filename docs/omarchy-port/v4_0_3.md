## What 4.0.3 is (for this port)

Release headline is Hermes / OpenClaw / T3 / Cursor CLI / Muse agentware plus
more security hardening. Almost all of the AI surface is Arch installers,
AUR packages, and menu rows — **not ported**.

The slice that touches Omaxian:

1. **Plugin auth / host-API boundary** — third-party plugins get
   `Plugin*Api` facades instead of live `ShellRoot` / registries; lock and
   polkit are isolated behind `AuthServiceStore` and an
   `omarchy.capabilities: ["authentication"]` first-party declaration.
2. **`keepLoaded` services** survive plugin hot-reload unload (auth store
   included).
3. **Kitty remote control** — `allow_remote_control socket-only` so embedded
   terminal sequences cannot drive remote control.
4. Small bar/panel API: `setCenterHoverRevealSuppressed` method + idleConfig
   facade fallback.

Skipped entirely: Hermes/OpenClaw/T3/Perplexity installers and removers,
`omarchy-theme-set-hermes` / `-t3code`, systemd sleep-hook ownership,
mise/sudo/fingerprint Arch paths, Broadcom DKMS, locate service units,
lock-plugin PAM hardening (lock remains `i3lock`).

## Smoke (after `./install.sh` && `./deploy.sh`, then **log out / log in**)

Do **not** run `omarchy-restart-shell` from an agent session.

```
omarchy-shell shell ping
omarchy-shell shell listPlugins | jq length
```

Then: bar widgets, launcher, weather/clock panels, theme switch, power menu.
Polkit stays disabled unless you opt in. Community plugins (if any) should not
see lock/polkit via `shell.serviceFor`.
