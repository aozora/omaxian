## What 4.0.4 is (for this port)

Release headline is the bespoke **linux-omarchy** kernel (default boot via
Limine), matching kernel headers for DKMS hardware drivers, and a webcam fix
on XPS systems. Entirely Arch/ISO/install-path work.

**Shell:** `diff -rq` of `shell/` between the v4.0.3 snapshot and the v4.0.4
checkout is empty — **byte-identical**. No QML / plugin / `shell.json` port
work.

**Bin:** only `omarchy-install-gaming-xbox-controllers` differs — Arch gaming
installer, **not ported**.

Skipped entirely: `install/hardware/*`, Limine defaults, kernel migrations,
acceptance/shell tests under `test/`, Broadcom/Tuxedo/yt6801/Intel PTL
helpers.
