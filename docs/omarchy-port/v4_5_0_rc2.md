## What 4.5 is (for this port)

Highlights that matter on Devuan/X11/i3:

| Upstream feature | Omaxian stance |
|---|---|
| 50 languages (`Commons/I18n`, `default/i18n/`, `omarchy-language`) | **Port** — shell strings + language file; locale generation is Debian/`locale-gen`, not Arch/`uwsm` |
| Per-monitor workspaces / floating workspaces + dock | **Partial** — i3 already has per-output workspaces; upstream `plugins/dock` is Hyprland — keep **`omaxian.dock`** local; do not replace with upstream dock this pass |
| Rebuilt notifications (`plugins/notifications`) | **Defer** — port still uses **dunst**; record as not-ported |
| Appearance menu / theme intros / video wallpapers (OWE) | **Defer** — Wayland/OWE; keep `hsetroot` / controlpanel wallpaper tab |
| Elsewhen world clock | **Decide later** — new `plugins/panels/elsewhen`; X11-safe candidate after Commons/Ui land |
| Quake terminal / keybind shuffle | **i3 binds** — optional later; document breaking Super+Ctrl chords from release notes |
| New default apps (Hype, Monologue, Signed, Disktree) | **Not ported** (Arch packages) |
| F1 installer / Limine / N1x / Snapdragon / Mac merge | **Not ported** |
| `Ui/OverlayWindow` (fullscreen WlrLayershell helper) | **X11 shim** — replace Hyprland/Wayland; never map a transparent full-screen surface that blacks out under picom glx (see `CenteredModal`) |
| `Commons/AudioNodes` | **Copy** — PipeWire node filter hints; harmless with pactl Audio graph |
| Agents panel expansion (23 providers) | **Partial** — remirror panel when Commons ready; Arch installers stay unported |
| Remote-session / passwordless-sudo indicators | **Defer** |
| Dictation indicator removed upstream | Port already dropped Dictation |

Breaking keybind changes from the RC notes should be reviewed against
`omaxian/.config/i3/config.d/` in a later commit (calculator / activity /
network / nightlight / notification chords).

## Quickshell

Local build remains **0.3.1**. New shell code uses existing QtQuick /
`Quickshell.Io` for I18n. No new QS module requirement spotted for the Commons
layer. OverlayWindow's upstream Hyprland/Wayland imports are **not** used in
the X11 shim. Re-check if later plugin remirrors need APIs beyond 0.3.1.

## Smoke (after foundations land)

Do **not** `omarchy-restart-shell` from an agent session. After `./scripts/deploy.sh`,
**log out / log in**, then:

```
omarchy-shell shell ping
omarchy-shell shell listPlugins | jq length
```

Click through bar widgets, audio/bt/network/power/weather, theme set, OSD,
reminders. Language: `omarchy-language list` / set a code and confirm bar
strings update without a QS restart (I18n file watch).
